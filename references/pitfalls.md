## 口径与数字

**1. 文档里的规模数字和真源差 1**
症状：审阅文档写「53 节点 / 62 边」，真源实际 52 / 63。
根因：手写、复制、升版本后没人复测。同一份文档另一处写「54 / 65」，也是错的。
修法：数字只能来自脚本输出；把「复测命令」写进维护约定，改一次跑一次。

**2. 便签/注释节点算不算节点，没人说清**
症状：同一份 DSL，有人数 52，有人数 51。
根因：画布便签（`data.type` 为空）在图里存在但不执行。
修法：口径写进产物页眉（「52 节点，含 1 个不执行的画布便签」），不要悄悄删掉。

**3. 「18 类枚举」这种数法本身有歧义**
症状：正文列了 18 个，真源顶层声明有 20 个。
根因：漏数了两个新加的类别，且没定义「类别」以什么为准。
修法：给可执行的判定式（顶层 `分类code：` 条目数），并把判定式写在证据栏里。

## 生成器（Python）

**4. `ValueError: unsupported format character '<'`**
症状：拼 HTML 的 `%` 格式化崩了。
根因：字面量 `width:100%` 里的 `%` 被当成格式符。
修法：模板串里写 `100%%`；或改用 f-string / `str.format`，别混用。

**5. `IndexError` / `TypeError: string indices must be integers`**
症状：生成阶段页时崩，索引越界或对字符串再取键。
根因：拿节点 id 当阶段 key 用；`[x['name'] for x in …][0]['name']` 多套了一层。
修法：先建显式映射表（`NAME = {stage['key']: stage['name']}`），别靠列表顺序。

**6. 深链变成 `#/n/{'value_selector': …}`**
症状：详情页里点「取值来源」跳到空白视图；还有 `#/n/env`、`#/n/sys`。
根因：把整个 `value_selector` **字典**当 id 传进了链接生成函数。
修法：所有来源单元格统一走一个 `sel_link(sel)`：解析出真节点 id 才生成 `<a>`，否则退化成 `<code>`。
教训：**引用扫描的输入形态不唯一（list / dict / 字符串），出口必须收敛到一个归一化函数。**

**7. 集合迭代顺序造成同一输入两种产物**
症状：`cmp` 两次构建，产物在第 76006 字节开始不同（表格行序变了）。
根因：`for nid in ids:`，而 `ids` 是 `set`。`PYTHONHASHSEED` 不同 → 行序不同。
修法：任何生成行序的循环先按稳定序（如 `D.ORDER`）排序；验收标准是
`PYTHONHASHSEED=1` 与 `PYTHONHASHSEED=99999` 两次构建 `cmp` 一致。

**8. 用 shell 循环核对 52 个行号区间，得到假阴性**
症状：脚本报「全部命中」，实际有几条没查到。
根因：zsh 默认不对未加引号的变量做词分割，循环只跑了一轮。
修法：结构化核对一律用 Python，不用 shell 字符串循环。

## 布局与缩放

**9. 「适应宽度」把图缩到 20%，谁都读不了**
症状：整张图能看，但字全是糊的；用户第一反应是「这图没用」。
根因：宽 6250px 的画布硬塞进 1250px 视口。
修法：宽图（>2400px）初始落到 ~0.62 的可读比例，配一行提示「这是地图不是清单」，
并让 `+/-` 阶梯覆盖到 20%（想看全局时仍能一键缩回去）。

**10. 缩放后右侧大片空白 / 尾部被裁**
症状：`.cinner` 缩放了，滚动区域没变。
根因：只改了 transform，没同步外层 `.canvas` 的宽高。
修法：两级容器，`.canvas` 尺寸 = 原始尺寸 × 当前比例，随每次缩放重算。

**11. 连线穿过节点、边标签读不出**
症状：图一铺满就成毛线团。
根因：照抄原画布坐标；边标签没有描边。
修法：重排（最长路径定列 + 重心法排行），盯 `crossings` 指标；标签用 `paint-order:stroke` 加背景色描边。

## CSS 与窄屏

**12. 390px 下文档横向溢出 +362px**
症状：手机上整页能左右拖。
根因：一个长段落套了 `.cite{white-space:nowrap}`。
修法：`white-space:normal; overflow-wrap:anywhere`；`nowrap` 只允许用在短徽标/单行代码上。
**每条 `nowrap` 都要在 390 档看一眼。**

**13. 产物里出现 `&lt;已脱敏&gt;` 这样的字面转义**
症状：正文看到 `<` `>` 的转义串。
根因：文案里直接写了 HTML 标签，而渲染器又对整段做了一次转义（它期望的是反引号）。
修法：文案层只写轻量标记（反引号），HTML 由渲染器生成；转义只做一次。

## 交互与可达性

**14. 首屏就有一个焦点环**
症状：刚打开页面，标题上就一圈蓝色 outline，像被选中了。
根因：路由初始化时把焦点交给 `<h1>`。
修法：加载时用 `go(false)`（不抢焦点），`hashchange` 时才 `go(true)`。

**15. 深色模式只在截图里看过一遍就交付**
症状：深色下部分文字对比度不足、SVG 边几乎看不见。
根因：SVG 描边写死了浅色值。
修法：所有颜色走 CSS 变量，含 SVG；两套主题各截一次图人工看。

## 自检脚本自己会骗人

**16. 命中测试报 `nodes: 0`，其实是探针跑在错误的视图上**
症状：脚本显示「0 个问题」，但节点可点数是 0。
根因：探针按顺序执行，前一步按了 `Esc` 已经跳回首屏，再对隐藏视图取矩形全是 0。
修法：**每个探针前显式导航回目标视图**，并把「探针视图 + 节点数」打印出来核对。
教训：自检脚本输出里的 `0` 有两种含义——「没有」和「我没看到」。必须打印分母。

**17. 用 `count('class="gnode"')` 数节点，得到 0**
症状：探针选不出视图，退化成随机首屏。
根因：真实 markup 是 `class="gnode t-llm is-answer"`，精确匹配不上。
修法：按前缀匹配 `class="gnode[ "]`；写探针脚本时先在真实产物上跑一遍再信它。
同批还有：`file://` 拼相对路径 → `net::ERR_INVALID_URL`，先 `os.path.abspath`。

**18. 命中测试的「在视野内」判据漏算了滚动容器**
症状：探针报「7 个节点在视野内，6 个可点」，看起来像 1 个被遮住的 bug。
根因：只比对了 `window.innerWidth/innerHeight`，没比对 `.gscroll` 自己的矩形——
落在视口内但被容器 `overflow` 裁掉的节点，中心点命中的是 `BODY`。
修法：可见区域取「视口 ∩ 滚动容器」，断言 `clickable == inview`，并让 `inview == 0` 也算失败
（探针没测到任何东西时，「0 问题」是自欺）。

## 安全

**A. 脱敏表自己成了泄漏源**
把生成器从临时目录搬进仓库时，`extract.py` 里硬编码着真实内网域名、HMAC 签名密钥和泄漏探针片段
——等于把凭证从 `/tmp` 复制进长期仓库，而且因为「在脚本里」显得可信。
修法：脱敏表按**结构**推导（主机形状 / 变量名含 secret|key|token 的长串赋值 / 带口令连接串 / 工具配置字段），
推导脚本只打印命中类别与数量；表本身 gitignore；产物和仓库分别扫一遍。

**B. 扫描器把找到的口令打印进日志**
`leak_scan` 输出「上下文片段」时直接贴出了 DSN 里的密码。
修法：输出前打码（长字母数字串 → `****`，IP 段 → `*.*.*.*`）。扫描器的输出也是日志。

**C. 扫描器把构建时生成的脱敏表也算成泄漏**
`leak_scan.py <产物> <生成器目录>` 会在 `redact.py`（推导出来的脱敏表，含真实内网 IP）上报红。
但这张表本来就是**不入库**的构建中间物——把它判成违规等于「正确配置的仓库永远无法通过这道门禁」，
于是大家会开始加 `|| true`，门禁就废了。
修法：扫描时读目录里的 `.gitignore`，被忽略的文件跳过，但**打印跳过几个、叫什么名**（见清单 16 的「打印分母」）。

**D. 汇报里复述敏感值**
任何时候不要把密钥、DSN、真实用户标识贴进对话、提交或文档；需要清单时只看 `.env.example` 这类样例。
